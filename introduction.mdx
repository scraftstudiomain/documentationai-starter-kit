## Overview

Scraft provides a centralized space to organize, manage, and collaborate on your project documentation. You create structured docs, track changes, and share knowledge efficiently across teams. Whether you document codebases, APIs, or processes, Scraft simplifies the workflow with intuitive tools and powerful search.

## Quick Start

Get up and running with Scraft in minutes. Follow these steps to create your first documentation project.

<Steps>

  <Step title="Sign Up" icon="user-plus">

    Visit `https://scraft.example.com` and create a free account. Verify your email to unlock full features.

  </Step>

  <Step title="Create a Project" icon="plus">

    Click "New Project" from the dashboard. Enter a name like "My API Docs" and select a template.

  </Step>

  <Step title="Add Your First Document" icon="file-text">

    Navigate to your project and create a new page. Use the markdown editor to add content.

````markdown
# My First Doc

Welcome to Scraft!

## Quick Tips

- Use `{headings}` for structure
- Add `**bold**` for emphasis
- Embed code blocks for examples
````

  </Step>

  <Step title="Publish and Share" icon="share-2">

    Click "Publish" to make your docs live. Generate a shareable link or embed in your site.

  </Step>

</Steps>
