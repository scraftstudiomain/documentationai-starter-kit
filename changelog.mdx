## How to Update

<Steps>

<Step title="Check Current Version" icon="package">

Run the version check command to see your installed version.

<CodeGroup tabs="npm,yarn">

````bash
npm list scraft
````

````bash
yarn list scraft
````

</CodeGroup>

</Step>

<Step title="Update Package" icon="upload">

Install the latest version using your preferred package manager.

<CodeGroup>

````bash
npm install scraft@latest
````

````bash
yarn add scraft@latest
````

</CodeGroup>

</Step>

<Step title="Restart Server" icon="refresh-cw">

Restart your Scraft development server to apply changes.

````bash
npm run dev
# or
yarn dev
````

</Step>

<Step title="Verify Update" icon="check-circle">

Confirm the new version is active and test your documentation spaces.

</Step>

</Steps>

## Migration Notes

<ExpandableGroup>

<Expandable title="Migrating from v1.x to v2.0" default-open="true">

If you're upgrading from v1.x, update your config files from YAML to JSON format:

````json
{
  "brandColor": "#EE964B",
  "spaces": [
    {
      "name": "default",
      "path": "./docs"
    }
  ]
}
````

Test thoroughly after migration, especially shared spaces.

</Expandable>

<Expandable title="Handling Breaking Changes">

Review deprecated shortcodes and replace with standard MDX components like `<Callout>` or `<Steps>`.

<Callout kind="alert">

Backup your documentation before applying updates.

</Callout>

</Expandable>

</ExpandableGroup>
